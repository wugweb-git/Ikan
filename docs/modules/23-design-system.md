# Module: Design System

## Purpose
Defines visual language, components, and UI consistency across the system.

## Scope
Owns:
- Design tokens
- UI components
- Accessibility rules

Does NOT own:
- Business logic

## Key Concepts
- Tokens (color, spacing, typography)
- Components
- Variants & states

## Component Specifications
- Button
- Input
- Card
- Modal

## Dependencies
- None

## Consumers
- All UI modules

## Admin / Control
- Managed via design updates
